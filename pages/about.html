About the project

Why MediFind exists

MediFind is a CSE326 front-end project that demonstrates how structured public facility information can make healthcare-resource discovery easier to search, scan and compare.

Problem

People often encounter inconsistent or incomplete information when comparing nearby clinics, labs, pharmacies and support facilities. Important details such as services, opening hours, verification and contact information may be spread across different sources.

Objective

Provide one searchable directory with a consistent profile format, useful filters, live availability indicators, comparison tools and browser-local feedback for a clear demonstration of a resource-discovery interface.

Technical approach

The site uses semantic HTML, responsive CSS, ES modules and vanilla JavaScript. A JSON file seeds localStorage on first load. No framework, build process, database, analytics or backend is required.

Important scope

The listings and verification states are sample data for demonstration. MediFind is not an emergency service, medical advice service or authoritative provider directory. Real deployments would require verified data sources, secure authentication and server-side controls.
